# Global Air Quality-Unsupervised Clustering

### Project Overview

This project analyzes global air quality data using Unsupervised Machine Learning techniques. The main goal is to identify natural groups and patterns in air quality and environmental conditions.

### Dataset

* Dataset: Global Air Quality Dataset
* Rows: 18,000
* Columns: 15
* Main Features: PM2.5, PM10, NO₂, SO₂, O₃, CO, AQI, Temperature, Humidity, Wind Speed

### Objectives

* Perform data exploration and preprocessing.
* Identify patterns in air quality data.
* Apply different clustering algorithms.
* Compare clustering performance using evaluation metrics.
* Analyze and visualize the identified clusters.
* Develop and save a machine learning pipeline.

### Machine Learning Algorithms

* K-Means Clustering
* Hierarchical Clustering
* DBSCAN

### Evaluation Metrics

* Silhouette Score
* Davies-Bouldin Index
* Elbow Method

### Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* SciPy
* Joblib
* Jupyter Notebook

### Project Workflow

Data Collection → EDA → Data Cleaning → Feature Selection → Feature Scaling → Clustering → Model Evaluation → Visualization → Cluster Analysis → Pipeline Development → Model Export

### Model Results

The clustering models were compared using Silhouette Score and Davies-Bouldin Index. The results showed different clustering patterns across the three algorithms.

### Output

The project identifies groups of observations with similar air quality and environmental characteristics and provides insights into the discovered clusters.

### Conclusion

This project successfully applied unsupervised machine learning techniques to identify meaningful patterns and groups in global air quality data. The clustering analysis provided insights into different air quality and environmental conditions, helping to understand similarities and variations within the dataset.
